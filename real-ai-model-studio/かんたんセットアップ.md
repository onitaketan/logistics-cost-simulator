# かんたんセットアップ（ターミナル・専門知識 不要）

このアプリをお手元のPCで動かす、いちばん簡単な手順です。
必要な操作は「インストール1回」「ダウンロード1回」「ダブルクリック1回」だけです。

## 1. Docker Desktop をインストールする（初回のみ）

1. https://www.docker.com/products/docker-desktop/ を開く
2. お使いのPCに合う版（Windows / Mac）をダウンロードしてインストール
3. インストール後、Docker Desktop を起動する（クジラのアイコンが Running になればOK）

## 2. アプリ一式をダウンロードする（初回のみ）

1. 次のリンクを開くと ZIP がダウンロードされます:
   https://github.com/onitaketan/logistics-cost-simulator/archive/refs/heads/claude/real-ai-model-studio-wmaett.zip
2. ZIP を展開（右クリック → すべて展開 / ダブルクリック）
3. 展開したフォルダの中の `real-ai-model-studio` フォルダを開く

## 3. 起動する

- **Windows**: `start-windows.bat` をダブルクリック
  - 「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」
- **Mac**: `start-mac.command` を**右クリック →「開く」**（初回のみ。2回目からはダブルクリックでOK）

初回は5〜15分かかります。黒い画面が自動で進み、完了するとブラウザが開きます。

- ログイン: `admin@example.com` / `ChangeMe123!`
- ログイン後、「ユーザー管理」画面でパスワードを変更してください

2回目以降の起動も、同じファイルをダブルクリックするだけです（数十秒で起動）。

## 止めたいとき

Docker Desktop を開き、Containers の一覧で `real-ai-model-studio` の停止ボタン（■）を押します。
データ（登録したモデル・案件・画像）は保存されており、次回起動時にそのまま残っています。

## 安全について

- 既定は**完全オフラインモード**です。登録した情報・プロンプト・生成画像がPCの外に送信されることはありません
- 画像生成は既定ではダミー（グレーの枠）です。実画像の生成に進みたくなったら Claude に相談してください

## うまくいかないとき

黒い画面に表示されたメッセージを**そのままコピーして Claude に貼り付けて**ください。
原因を調べて直します。
